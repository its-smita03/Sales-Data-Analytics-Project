# Sales Data Analytics Project

## Project Overview
This project analyzes sales data to identify trends, patterns, and business opportunities.

## Objectives
- Clean and prepare sales data.
- Perform Exploratory Data Analysis (EDA).
- Create data visualizations using Python.
- Build an interactive Power BI dashboard.
- Provide business insights and recommendations.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Power BI
- Git and GitHub
